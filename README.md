## Инкапсуляция — это принцип ООП, который скрывает внутреннее состояние объекта и позволяет управлять доступом к нему — чтобы нельзя было случайно присвоить неправильные данные.
## Data-класс (класс данных) — это специальный тип класса в Kotlin, предназначенный в первую очередь для хранения данных. 
Основное преимущество data-классов — автоматическая генерация стандартных методов, которые обычно
приходится писать вручную

data class Item(
    val id: Int,
    val name: String,
    val quantity: Int) {
    override fun toString(): String {
        return "Id предмета: $id\nИмя: $name\nКоличество: $quantity\n"
    }
}
## Абстрактный класс — это базовый класс, от которого нельзя создать объект напрямую. Он используется для описания общей логики и структуры для группы связанных классов.
Может содержать:
➢ обычные методы с реализацией
➢ абстрактные методы (без реализации)
➢ свойства (абстрактные и обычные)
Используется, когда нужно:
➢ общее поведение и состояние
➢ базовый класс для иерархии объектов
abstract class Human(val name: String){
    open fun hello(){
        println("My name is: $name")
    }
}
## Интерфейс — это контракт поведения, который класс обязуется реализовать.
Особенности:
➢ не хранит состояние
➢ может содержать default-реализацию методов
➢ один класс может реализовывать несколько интерфейсов
interface Movable{
    var speed: Int
    val model: String
    val number: String
    fun move()
    fun stop() {
        println("станавливаемся...")
    }
}
